# Banking Loan Risk Analysis Dashboard

## Project Overview

This project analyzes banking loan data using Microsoft Power BI.

## Dataset

- 20,000 Loan Records
- Customer Information
- Loan Amount
- Interest Rate
- Credit Score
- Employment Status
 
## Tools Used

- Power BI
- Excel
- Data Modeling
- DAX
- Data Visualization

## Dashboard Pages

- Executive Dashboard
- Customer Analysis
- Loan Analysis
- Risk Analysis

## Key KPIs

- Total Customers
- Total Loan Amount
- Average Credit Score
- Average Annual Income
- Average Interest Rate
- Current Balance

## Insights

- Loan purpose distribution
- Customer demographics
- Risk analysis
- Credit score trends
